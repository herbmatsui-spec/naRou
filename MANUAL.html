はじめに

naRou: Masterpiece Edition とは

naRou: Masterpiece Edition は、Python + tcod で実装された本格ローグライクRPGです。Elona（エロナ）にインスパイアされたシステムを現代的なアーキテクチャで再構築し、独自の「異世界マルチバース構想」を実装しています。

2つのゲームモード

| モード | 説明 | |--------|------| | グラフィカルモード | SDL/tcod によるタイルベース描画（デフォルト） | | テキストモード | GPU/SDL不要、ASCII/ANSIカラー描画（CI・SSH・コンテナ対応） |

ワールド構成

  • Aの世界：スキル喰い（Skill Eater RPG） - 本編メインストーリー
  • Bの世界：錬金術の深淵 - Phase 5 以降で解放予定
  • naRou Core - クラシックなローグライク機能（ダンジョン探索、スキルツリー、ペット育成）

インストールと起動

必要環境

  • Python 3.10 以上 (3.11〜3.14 推奨)
  • 依存パッケージ: tcod, pyyaml, cryptography, numpy, pydantic, python-dotenv, pillow, scipy
  • オプション: pygame, simpleaudio (音声再生用、未インストールでも起動可能)

インストール手順

```bash

リポジトリクローン

git clone cd narou

依存ライブラリインストール

pip install -r requirements.txt

オプション: 音声ライブラリ

pip install pygame simpleaudio ```

起動方法

通常起動（グラフィカルモード）

```bash

方法1: 統合システムメニューから起動

python main.py

方法2: 直接ゲームモジュール起動

python -m game

方法3: インストール後、コンソールスクリプトで起動

pip install -e . narou ```

テキストモード起動

```bash

環境変数指定

NAROU_FORCE_TEXT=1 python main.py

またはメニューから「3. テキストモードで起動」を選択

python main.py

→ 3 を入力

```

ヘッドレス自動判定

```bash

run.py は環境を自動判定して適切なモードで起動

python run.py ```

Webブラウザ版デモ

```bash

ブラウザで直接開く（サーバー不要）

demos/demo_skill_eater_showcase.html

またはWebバックエンド付きで起動

python main.py --open

ブラウザで http://localhost:8080 を開く

```

ゲームシステム詳細

1. AP (アクションポイント) 制戦闘

全キャラクター（プレイヤー・敵・ペット）は 1ターン 2AP を持ちます。

| アクション | APコスト | 備考 | |-----------|---------|------| | 移動 (1マス) | 1 | 対角移動も1AP | | 近接攻撃 | 1 | 向きが自動更新される | | 射程攻撃 (F) | 1 | 視線必須、最寄り敵を自動標的 | | 呪文詠唱 (1-8) | 1 | MP消費、成功率判定あり | | 待機 (./Space) | 0 | APを消費せずターン経過 | | 喰らい (V) | 1 | 隣接弱体化敵が対象 | | 解析 (X) | 0 | 無料アクション |

戦術のポイント: - AP管理が生死を分ける。無駄な移動を避け、背後を取る - 敵も同じAP制。敵のAP枯渇を狙って安全に接近可能 - 背後攻撃は ダメージ ×1.5（会心とは別乗算）

2. 向きシステム (Facing)

全エンティティは facing (N/S/E/W) を持ちます。

  • 移動時: 移動方向を向く
  • 攻撃時: 攻撃対象の方を向く
  • 待機時: 向き維持
  • 背後判定: 攻撃者が対象の背後（向きの反対側）にいる場合 ×1.5倍

3. 呪文システム (8種完全実装)

| # | 呪文名 | 効果 | MP | 射程 | 特記事項 | |---|-------|------|----|------|---------| | 1 | 魔矢 | 単体必中ダメージ | 5 | 8 | 外れない、貫通なし | | 2 | 火炎球 | 範囲AoEダメージ | 12 | 6 | 半径2、味方巻き込み注意 | | 3 | 氷の矢 | 直線貫通ビーム | 8 | 10 | 凍結付与確率、壁貫通不可 | | 4 | 雷撃 | 直線貫通ビーム | 10 | 8 | 麻痺付与確率、水上で威力上昇 | | 5 | 軽傷治癒 | HP回復 (小) | 6 | 自身 | 戦闘中使用可 | | 6 | 重傷治癒 | HP回復 (大) | 15 | 自身 | 状態異常も一部回復 | | 7 | テレポート | 安全マスへ移動 | 20 | 全域 | 敵から離れた場所優先 | | 8 | 加速 | 速度バフ (3ターン) | 10 | 自身 | 次3ターン AP+1 |

詠唱失敗時: 魔力暴走ダメージを受ける（MPの10〜30%）

4. 敵AI・意図テレグラフ

  • 12種の通常敵 + 2種のボス が個別実装
  • data/monster_abilities.yaml の15能力を組み合わせ
  • 意図表示: 敵頭上に ⚔突撃 / ✷詠唱 / ➛逃走 / ✚回復 アイコン表示
  • 真実性保証: AIビヘイビアツリーに実在しない行動は表示されない（テスト強制）

5. アイテム・接尾辞システム

接尾辞 (Affix) - 23種定義済み

  • 全戦闘系接尾辞は 利得と代償の両方 を持つ
  • 例: 《秃鷹の》 筋力+3 / 回避-2
  • 品質連動ロール: GOD品=必ず2個、BAD品=接尾辞なし
  • アイテム名に [接尾辞] 形式で表示

呪い接尾辞 (4種)

| 呪い名 | ペナルティ | |-------|-----------| | 薄れ | 全ステータス -10% | | 硝子 | 被ダメージ +50% | | 衰弱 | 最大HP -30% | | 怠惰 | AP回復 -1/ターン |

鑑定システム

  • 未鑑定アイテムは接尾辞情報が ??? 表示
  • 鑑定にはゴールド消費（品質×レベル×基本コスト）

Aの世界：スキル喰い 完全ガイド

Phase 0: 転落と覚醒

開始条件: ゲーム開始時自動

ストーリー: バベルタワー監査官→不正暴露→権限剥奪→深度700m廃棄スラム投棄

初期スキル: - 《基礎解析》 (Scan): 敵情報表示 - 《喰らい (Devour)》: スキル捕食の核心スキル

攻略のコツ: - まずは生存最優先。戦闘は避け、解析で情報収集 - 《基礎解析》は頻繁に使って敵の弱点把握 - セーフハウス（安全エリア）を見つけたらそこで休息

Phase 1: 禁忌の《喰らい》と抜け殻

Devour (喰らい) システム

発動条件: 隣接敵が HP 50%以下 または 状態異常中

手順: 1. X で解析し、対象の弱点・スキル・成功率確認 2. 攻撃/呪文で敵を弱体化（HP50%以下に） 3. 隣接して V で《喰らい》発動 4. 成功時: 敵スキル取得、敵は Husk (抜け殻) 化

成功率計算: 基本成功率 = 50% + (解析Lv × 5%) + (対象HP割合 × -30%) + (状態異常ボーナス) 麻痺/睡眠: +20% 毒/出血: +10%

Husk (抜け殻) の特徴: - 意志なし、行動不能、経験値なし - 一部は《召使い化》でペット/配下に可能 (Phase 2以降)

Toxicity (毒性) 管理

  • 捕食ごとに毒性蓄積 (スキルレアリティ×基本値)
  • 80%超過: 毎ターン HP 減少 + スキル使用失敗率上昇
  • 100%到達: 《暴走》発動、大ダメージ + ランダムスキル喪失
  • デトックス: セーフハウスで休息 (1ターン -5%)、専用アイテム使用

Phase 2: キメラ合成炉とスラム拠点

キメラ合成炉 (Shift + T)

合成ルール: - スキル2種を選択 → 合成実行 - 同系統: 強化版生成 (Lv+1、威力上昇) - 異系統: キメラスキル 生成 (複合効果、新規スキルID)

合成例: 《初級火炎》 (Fire Lv1) + 《思考加速》 (Mind Lv1) ↓ 《変異融合：業火の超思考》 (Fire+Mind Lv2) 効果: 火炎ダメージ + 詠唱速度上昇 + MP効率化

合成コスト: ゴールド + 素材スキル消費 (元スキルは失われる)

失敗時: 毒性急上昇 + 素材スキルのみ消失

スラム解放戦線拠点

施設とアンロック条件:

| 施設 | 必要投資 | 効果 | |------|---------|------| | セーフハウス | 初期解放 | 休息・デトックス・セーブ | | 地下闇市場 | 廃品50 + スキル3 | 希少アイテム購入、スキル売却 | | 医療ステーション | 廃品100 + スキル5 | 状態異常全回復、毒性-20% | | ペット訓練所 | 廃品150 + スキル7 | ペット進化石購入、融合解放 | | 合成炉強化 | 廃品200 + スキル10 | 合成成功率+15%、キメラ枠拡張 |

投資素材: - 廃品: ダンジョン探索・敵ドロップ・Husk分解で入手 - 余剰スキル: 使わないスキルを「投資」コマンドで変換

ペット自動派遣 & 環境パズル

  • ハスクハウンド を廃品処分場へ派遣 (リアルタイム数時間で完了)
  • 戻り時に廃品・レア素材・スキル断片を持参
  • 属性スキルで環境ギミック解除: 氷壁(火炎)、電子隔壁(雷)、毒沼(浄化)等

Phase 3: 神格化アセンションと因果律ボス

神格化星座盤 (Ascension Board)

  • グリッド配置: 5×5 または 7×7 マスにマスタースキル装着
  • 属性リンク: 隣接する同属性スキルでシナジーパッシブ発動
  • 属性: Void / Flame / Light / Ice / Lightning / Shadow / Holy / Chaos

シナジー例: Flame × Flame 隣接 → 《業火の加護》: 火炎耐性+50、火炎威力+30% Void × Light 隣接 → 《虚光の均衡》: MP自然回復+5/ターン、全属性耐性+10

地下闘技場 & 指名手配ハイスト

  • 闘技場: 段階的ボスラッシュ、勝利ごとにユニーク報酬
  • 指名手配: ミダス商会幹部10名、各々固有の弱点・行動パターン
  • 弱点突破で《支配者の断片》入手、星座盤解放スロット拡張

因果律執行神『クロノス・ミダス』 戦

フェーズ構成: 1. 物理フェーズ: 高火力近接、背後取り必須 2. 因果律フェーズ: 行動予測無効化、確率操作攻撃 3. 概念フェーズ: 《概念喰らい》必須、通常攻撃無効

攻略ポイント: - Phase 1: 氷/雷で足止め、背後から連撃 - Phase 2: 意図表示が嘘になる → 解析(X)で真実確認 - Phase 3: 《概念喰らい》発動まで生存、毒性管理徹底

Phase 4-5: 概念結晶化とマルチバース跳躍

概念結晶化

条件: 同系統スキル 3種以上 所持

手順: 1. 星座盤または専用メニューから「結晶化」選択 2. 対象スキル3つを選択 → 1つの「概念結晶」に圧縮 3. 元スキルは消失、結晶はスロット1枠で3スキル分の効果

結晶の種類: | 系統 | 概念結晶名 | 効果 | |------|-----------|------| | 火炎 | 《焔の概念》 | 全火炎スキル効果内包、火炎無効貫通 | | 氷結 | 《氷の概念》 | 全氷結スキル効果、凍結無効化 | | 精神 | 《心の概念》 | 全精神スキル効果、MPコスト-50% | | 虚無 | 《虚の概念》 | 全虚無スキル効果、概念攻撃耐性 |

時空金庫 (Temporal Vault)

  • スロット: 最大 3〜5 枠 (拠点投資で拡張)
  • 保存対象: 概念結晶、ユニーク装備、永続パッシブ
  • 持ち越し: 次回プレイ/次ワールド (Bの世界) へ引き継ぎ

次元ゲート開放 & エピローグ

解放条件: 1. クロノス・ミダス撃破 2. スラム解放戦線拠点フルアンロック 3. 概念結晶 3つ以上作成 4. 時空金庫に引き継ぎアイテム確定

エピローグ: スラム住民の独立を見届け、concept_eater_mark を刻印され、次元ゲートへ。

ペット育成システム

契約

  • 敵を弱体化 → C キーで会話/交渉 → 契約成立
  • 契約条件: レベル差、性格相性、贈り物アイテム

進化

  • レベル上限到達 + 進化石/特定アイテム使用
  • 分岐進化: 種族ごとに 2〜3 ルート
  • 例: スライム → (火炎石) → フレイムスライム / (氷結石) → アイススライム

融合

  • ペット2体 + 融合触媒 → 新種族生成
  • 親のスキル/ステータスを確率継承
  • 稀に 突然変異 でレア種族誕生

| 指示 | 動作 | |------|------| | 付き従う | プレイヤー後方維持、自動戦闘 | | 待機 | 現在地で待機、敵接近で自動戦闘 | | 探索 | 周囲自動探索、アイテム回収 | | 撤退 | HP低下時自動離脱、安全地帯へ |
