# 🎮 Aの世界（スキル喰い）詳細実装計画書 Part 3

本ドキュメントは、「スキル喰いの異世界倒産」のシステム実装計画 Part 1, 2に続く、最終フェーズ（Phase 7〜8）の要件設計書です。ここではゲームのコアロジック自体をハックする終盤の展開と、周回プレイの仕組みを定義します。

---

## 🟩 Phase 7: マスタースキルと法則書き換え

### 7.1 ターゲットとするユーザー体験
**「神の視点を手に入れ、法則を書き換える万能感」**
ゲーム終盤、世界の管理者たる「世界スキル銀行頭取」からマスタースキルを奪取し、プレイヤー自身がゲームエンジンの変数（物理法則）に直接干渉する、究極のカタルシスを提供します。

### 7.2 実装要件定義

#### 7.2.1 法則書き換えエンジン (Rule Override System)
通常、スクリプト内でハードコード（またはConfig定義）されているゲームの基本定数に、実行時にオーバーライド（介入）できる特権APIレイヤーを構築します。

- **書き換え可能なグローバル変数（例）**:
  - `GlobalRule.DamageMultiplier`: 全体ダメージ倍率（デフォルト 1.0）
  - `GlobalRule.Gravity`: 魔法の落下速度やフィールドの挙動（アクション要素がある場合）
  - `GlobalRule.DevourSuccessRateOverride`: 喰らい成功率の強制書き換え
  - `GlobalRule.SpawnRate`: 敵の出現率（ゼロにしてエンカウントを消す等）

#### 7.2.2 コンソールUIの実装
- マスタースキル入手後、メニュー画面に「管理者コンソール」タブが追加される。
- プレイヤーは、チートコードを入力するようにUI上のトグルやスライダーを操作し、上記の `GlobalRule` をリアルタイムで変更できる。
- （世界観的演出として）画面に「ROOT権限を奪取しました。システム変数を解放します」というハッカー風の演出を入れる。

#### 7.2.3 最終決戦用ギミック
- 頭取とのバトルでは、敵がターンごとに `GlobalRule` を書き換えてくる（例：「回復魔法無効化フラグをTrueにした」）。
- プレイヤーは自分のターンで、マスタースキルの力を使ってそのフラグをFalseに戻したり、逆に「敵の防御力ゼロ」フラグをTrueにしたりする、**「ルールの奪い合い」**というメタ戦闘を実装する。

### 7.3 マイルストーン7（成果物）
- [ ] ゲーム内のグローバル定数をオーバーライドする特権管理クラスが動作すること。
- [ ] メニュー画面から変数を変更でき、即座に戦闘やフィールドの挙動に反映されること。

## 🟩 Phase 8: メタ進行と輪廻転生（エンドコンテンツ）

### 8.1 ターゲットとするユーザー体験
**「絶望的な状況を覆す周回プレイ（強くてニューゲーム）」**
全てを奪われても、喰らったスキルという「経験」だけは次代へ持ち越すことができる、ローグライト的なリプレイ性と成長の喜びを提供します。

### 8.2 実装要件定義

#### 8.2.1 資産継承システム (Reincarnation System)
ゲームクリア（または倒産・全滅によるゲームオーバー）時に実行されるメタセーブ処理。

- **資産の精算**:
  - 現在所持している全スキルの `MarketValue`（市場価値）を合計し、それをメタ通貨（カルマ、または継承ポイント）に変換する。
- **引き継ぎUI**:
  - 次周回開始前（Title画面後）に「継承ダッシュボード」を開く。
  - ポイントを消費して、前世で持っていた特定の強力なスキルを初期からアンロックしたり、ステータス倍率を上げたりできる。

#### 8.2.2 世界銀行の封印解除（周回アンロック）
- クリア回数（周回数）をグローバルセーブに記録。
- 周回数に応じて、1周目では絶対に入れなかったダンジョンや、戦えなかった強敵（初代スキルイーター等の隠しボス）のアクセス制限フラグを解除する。
- **真のエンディングルート**:
  - 特定の周回数以上かつ、隠しボスを喰らっている場合のみ、シナリオが分岐し「スキル制度自体の破壊」か「新たな神への就任」かを選択できるイベントフラグを実装。

### 8.3 マイルストーン8（成果物）
- [ ] ゲームオーバー/クリア時に正しくポイント計算が行われ、メタセーブファイル（JSON等）に保存されること。
- [ ] ニューゲーム時にメタセーブを読み込み、引き継いだスキルやステータスが正しく初期ステートに反映されること。
