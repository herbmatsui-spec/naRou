# 🎮 Aの世界（スキル喰い）詳細実装計画書 Part 2

本ドキュメントは、「スキル喰いの異世界倒産」のシステム実装計画 Part 1に続く、Phase 4からPhase 6までの要件設計書です。

---

## 🟩 Phase 4: 従属システム（洗脳パーティ）とAI制御

### 4.1 ターゲットとするユーザー体験
**「空っぽの敵を再利用する背徳的パーティ編成」**
プレイヤーがスキルを奪い尽くした敵を、ただの死体にするのではなく、自分の都合の良い「手駒」として再利用・カスタマイズするダークファンタジーならではの背徳感を提供します。

### 4.2 実装要件定義

#### 4.2.1 「空っぽ（Husk）」ステートの実装
敵から全てのスキル（または固有スキル）を喰らい尽くした時、死亡させずに特殊ステートに移行させます。

- **Husk（抜け殻）ステート**:
  - HPは1で固定。戦闘終了時、このステートの敵がいる場合「捕獲（Capture）」イベントが発生。
  - キャラクターの自我データ（Flavor Textやセリフ）が破損状態（文字化け等）に移行。

#### 4.2.2 移植（Transplant）インターフェース
アジトの「再教育施設」にて、Husk状態のNPCに自分の余っているスキルを移植します。

- **スキル枠の制限**:
  - NPCの素体（元々のレアリティ等）によって、移植できるスキルのコスト上限（メモリ上限）を設ける。
- **忠誠度（Loyalty）パラメータ**:
  - 初期値は低い。プレイヤーが強力なスキルを与えたり、戦闘で勝利を重ねるごとに上昇。
  - 忠誠度が低いと、戦闘中に命令を無視したり、移植されたスキルを暴走させたりする。

#### 4.2.3 従属AIシステム
- 行動パターンは移植されたスキルに依存する。
- 例：回復スキルと挑発スキルを移植した場合、AIは自動的に「ヒーラー兼タンク」として振る舞うロジックツリーを構築する（Utility AIの採用）。

### 4.3 マイルストーン4（成果物）
- [ ] 敵を捕獲し、アジトのUI上で所持スキルを渡して「従属スキル保有者」としてパーティに編成できること。
- [ ] 戦闘中、従属キャラクターが移植されたスキルを使って自動または手動で行動できること。

## 🟩 Phase 5: 派閥経済と拠点（企業買収）システム

### 5.1 ターゲットとするユーザー体験
**「資本主義の手のひら返し・成り上がり実感」**
スキル格差社会において、力（資本）を得ることで世界の見え方やNPCの扱いが劇的に変わる経営・侵略カタルシスを提供します。

### 5.2 実装要件定義

#### 5.2.1 派閥影響力と好感度エンジン (Faction Engine)
- **管理される派閥**: 「ミダス商会」「スキル開放戦線」「世界スキル銀行」「闇市場」。
- **パラメータ影響**:
  - プレイヤーの「現在のスキル資産価値の合計」が、各派閥からの「待遇（Tier）」を決定する。
  - 例：資産価値が10,000アルドを超えると、ミダス商会の一般店舗が利用可能になり、衛兵の態度が「見下し」から「畏怖」に変わる。

#### 5.2.2 市場価値変動システム (Dynamic Economy)
- プレイヤーが大量の同系統スキル（例：初級剣術）を闇市場に売却すると、そのスキルの市場価格が暴落する。
- 逆に、プレイヤーがミダス商会の支店を潰すと、商会系のスキルの価値が高騰するなどの需給シミュレーションロジック。

#### 5.2.3 拠点拡張と企業買収
- **アジトのアップグレード**:
  - 資金（アルド）と奪った「企業秘密スキル」を消費して、スキル開放戦線の施設をアップグレードする。
  - 施設Lv上昇により、従属可能人数増加、合成の大成功確率アップなどの恩恵。
- **テイクオーバー（買収バトル）**:
  - ボスを倒すと、そのマップ（支店など）が「自陣営の拠点」に反転し、毎ターンの定期収入（アルド）を生み出す。

### 5.3 マイルストーン5（成果物）
- [ ] プレイヤーの所持スキル価値に応じて、NPCのダイアログが動的に変化するシステムの実装。
- [ ] 拠点をアップグレードし、ターン経過（または戦闘回数）に応じて資金が手に入る機能の実装。

## 🟩 Phase 6: クエストエンジンとメタ攻略の統合

### 6.1 ターゲットとするユーザー体験
**「抜け道を突くメタ攻略の快感」**
正攻法では絶対に勝てない敵を、「このスキルとあのスキルを合成して特定のフラグを折れば無力化できる」というパズル的な攻略法で圧倒する楽しさを提供します。

### 6.2 実装要件定義

#### 6.2.1 クエスト進行管理システム (Quest State Machine)
- フェーズ進行（1.0〜3.5等）に応じたグローバルステート管理。
- **フラグ駆動型イベント**:
  - `RequireSkills`: クエスト開始や特定ルート進入に、特定のスキル（またはタグ）の所持を要求。
  - `Branching`: 「相手を殺す」「スキルを奪って生かす」「配下にする」によるルート分岐。

#### 6.2.2 メタギミック（ボス特効）の実装
- **例：ドン・ミダスの《黄金錬成》攻略**:
  - 通常は戦闘開始2ターンで全体即死が発動。
  - しかし、プレイヤーが事前に《物質置換》スキルと《火炎》スキルを【合成】して《黄金溶解》をクラフトして所持している場合、戦闘開始時のイベントハンドラがそれを検知し、即死発動を無効化（インターセプト）する。
- このような「特定スキルの所持・発動が、既存のスクリプトを強制上書きする」Observerパターンの構築。

### 6.3 マイルストーン6（成果物）
- [ ] 序盤〜中盤のメインクエストが進行し、クエストジャーナルが更新されること。
- [ ] 強敵に対し、特定の合成スキルを持ち込むことでボスの行動パターンや即死ギミックが上書きされるメタ戦闘が動作すること。
