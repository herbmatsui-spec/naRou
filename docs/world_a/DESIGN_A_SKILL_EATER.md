## 1. プロジェクト概要

### 1.1. コアコンセプト
**「スキルが資産・通貨・階級」な世界で、最底辺スキル《解析》だけを武器に「スキルを喰らって成長する」異色の育成RPG**

本作は、全てが「スキル」という資本で回る極端な資本主義ファンタジー世界を舞台に、底辺から頂点へと這い上がる下剋上RPGです。プレイヤーは初期状態で何の戦闘力も持たない《解析》スキルのみを所持していますが、「敵のスキルを奪い、自分のものにする」という禁忌の能力【スキルイーター】として覚醒し、巨大な資本勢力「世界スキル銀行」の解体を目指します。

### 1.2. 世界観・シナリオフック
- **舞台：アルディナ商業連合**
  スキルが単なる能力ではなく、「証券化・取引・相続」される資本主義の極致にある世界。ここではスキルの強さや希少性がそのまま身分（階級）となり、強力なスキルを持つ者は貴族として振る舞い、ノースキルやハズレスキルしか持たない者は労働奴隷として搾取される「スキル格差社会」が形成されています。
- **主人公**
  元・大手スキル商会「ミダス・ホールディングス」の新卒社員。入社初日の適性検査で、スキルの構造を見るだけで実用性のない無価値なハズレスキル《解析》しか持たないことが発覚し、即日クビを宣告されます。絶望の中、彼は自らが「スキル喰い（スキルイーター）」と呼ばれる規格外の覚醒者であることに気づきます。
- **核心対立構造**
  - **ミダス商会（主人公の元勤め先）**: 序盤の敵対勢力。スキルを不当に買い叩き、労働者を搾取するブラックメガコーポ。
  - **スキル開放戦線**: 主人公が合流するレジスタンス組織。「全ての者に平等なスキルを」と掲げるが、内部にも腐敗や過激派を抱える。
  - **世界スキル銀行**: 本作のラスボス勢力にして独占資本。世界のスキルの流通を支配し、「マスタースキル」によって世界の法則そのものを独占している。
- **最終ゴール**
  世界スキル銀行の最深部に君臨する「マスタースキル（世界法則そのもの）」を喰らい、この歪んだスキル資本主義制度そのものを解体・再編すること。

## 2. 既存システムへのマッピングとリデザイン

ベースとなる `naRou` フレームワークの既存システムを、本ワールド（W4: `skill_eater`）向けに以下のようにリデザイン・オーバーライドします。

### 2.1. 神々 (gods.yaml) ＝ 《概念の柱》
従来作における「神々への信仰」は、本作では**「特定概念のスキルをどれだけ喰らったか」**という実績ベースの信仰システムに置き換わります。
- **9柱の概念**: 《剣》《炎》《金》《欺瞞》《死》《絆》《進化》《虚無》《始まり》
- **信仰のメカニクス**: 例えば、炎属性の魔法やスキルを持つ敵を多数喰らうと、《炎》の概念値が上昇し、《炎》の柱からパッシブボーナスや上位派生スキルのアンロック権が与えられます。

### 2.2. 派閥 (factions.yaml) ＝ 商会・組合・レジスタンス
- **ミダス商会**: 敵対派閥。倒すことで「企業秘密スキル」や「裏帳簿（換金アイテム）」をドロップ。
- **スキル開放戦線**: 味方派閥。貢献度（喰ったスキルを戦線に寄付・共有する）に応じて、アジトの施設拡張や仲間NPCの強化が行われる。
- **世界スキル銀行**: 最終敵対派閥。彼らが派遣してくる「監査官」や「回収屋」は超強力なレアスキルを保持しており、格好の「獲物」となる。
- **闇スキルブローカー**: 中立派閥。違法スキルの売買や、特定のターゲット（レアスキル持ち）の位置情報を提供する情報屋。

### 2.3. ジョブ (jobs.yaml) ＝ 「スキル階級」
ジョブは職業ではなく、社会的な「身分・階級」を表すものとして機能します。上の階級に行くほど、強力なバフや特定のNPCとの交渉権限が得られます。
1. **ノースキル（奴隷）**: 初期状態。全ステータスにデバフ。
2. **コモンスキル保有者（庶民）**: デバフ解除。一般的な店が利用可能。
3. **レアスキル保有者（貴族）**: ステータスボーナス。高級店利用、関所パス。
4. **ユニークスキル保有者（英雄）**: 大幅ボーナス。派閥の幹部と直接交渉可能。
5. **コンセプトスキル保有者（神話級）**: 概念の柱にアクセス可能。
6. **スキルイーター（主人公専用・制度外）**: 階級制度を無視し、全階級の特権を「偽装（喰ったスキルを使って身分を偽る）」できる。

### 2.4. スキルツリー (skill_trees.yaml) ＝ 「喰らいツリー」
固定のスキルツリーではなく、**動的構築型（ダイナミック）スキルツリー**を採用します。
- **基盤《解析》**: 全ての始まり。これをレベルアップさせることで、「喰らい」の成功率や合成のレシピ枠が拡張されます。
- **派生機能**: 《喰らい》《吸収》《複製》《合成》《逆引き》《概念喰い》《法則書き換え》
- **ツリーの成長**: 敵から新しいスキルを喰らうたびに、ツリーの枝としてそのスキルが動的に追加され、そこからさらに独自の進化先（合成先）が伸びていきます。

### 2.5. ペット (pet_*.yaml) ＝ 「従属スキル保有者（スキルホルダー）」
モンスターをテイムするのではなく、「人間やモンスターからスキルを喰らい尽くして空っぽ（廃人化）にした後、主人公が新たにスキルを移植して従属させる」というダークなシステムです。
- **再教育と移植**: 空っぽの肉体に、余っているコモンスキルなどを移植することで忠実な部下として使役できます。
- **パーティ編成**: 育てた「従属スキル保有者」をパーティメンバーとして戦闘に参加させます。

### 2.6. 輪廻転生 (reincarnation.yaml) ＝ 「スキル継承＝前世の喰ったスキル資産」
ゲームクリア後、または全滅時（倒産・破産）のメタプログレッションシステムです。
- **資産の持ち越し**: 周回ごとに、「前世で喰ったスキル」をポイント換算し、次周への持込スキルや初期資金（スキル資産）として継承します。
- **封印解除**: 周回を重ねるごとに、世界スキル銀行が隠している「世界の真実」や封印されたエリアへのアクセス権が解放されていきます。

### 3.2 探索システム（ダンジョン探索・移動・環境音）

**概要**: フィールド探索・ダンジョン内部の移動・足音・扉・トラップ・宝箱を統合するシステム。§4.1 序盤の「スラム街」から開始し、ダンジョン部屋を順次探索して敵・報酬・情報を獲得する基本ループを支える。

**データ構構造** (`skill_eater_exploration_system.py`):

```python
@dataclass
class DungeonRoom:
    room_id: str
    name: str
    description: str
    has_treasure: bool = False
    has_trap: bool = False
    enemies: List[CharacterState] = field(default_factory=list)


@dataclass
class ExplorationResult:
    action_type: str  # 'STEP', 'MOVE_ROOM', 'OPEN_DOOR', 'LOOT_CHEST', 'ESCAPE', 'TRAP'
    message: str
    current_room_id: str
    played_sounds: List[str] = field(default_factory=list)
    presentation_events: List[PresentationEvent] = field(default_factory=list)
```

**初期部屋マップ** (開始地点: `slum_alley` → §4.1「スラム街」と整合):
| room_id | 名称 | 説明 | 宝箱 | トラップ |
|---|---|---|---|---|
| `slum_alley` | スラムの裏路地 | 薄暗く湿った路地。遠くでサイレンが鳴り響く。 | No | No |
| `underground_market` | 地下闇市場通り | 違法スキルの密売人たちが行き交う。 | No | No |
| `midas_tower_entrance` | ミダスタワー正面玄関 | 巨大な黄金の扉がそびえ立つ。 | No | No |
| `vault_chamber` | バベルの金庫室 | 秘匿された至高のスキルが眠る金庫。 | Yes | No |

**主要アクション**:
- `STEP`（1歩前進）— ランダム足音 `footstep00〜09.ogg` 再生
- `MOVE_ROOM`（部屋移動）— 扉開閉演出・環境音
- `OPEN_DOOR`（扉を開く）— 扉音・必要なら鍵判定
- `LOOT_CHEST`（宝箱を開ける）— 宝箱音・報酬取得
- `ESCAPE`（逃走）— 逃走音・部屋リセット
- `TRAP`（トラップ発動）— トラップ音・ペナルティ

**演出・音響連携**: `SkillEaterPresentationSystem`（Emote）および `SkillEaterAudioSystem`（SE）と統合。各アクションで `presentation_events` と `played_sounds` を返し、フロントエンドで再生。

**実装状況**: 実装・テスト済 (`skill_eater_exploration_system.py`, `test_skill_eater_presentation_integration.py`, `test_skill_eater_audio_integration.py`)。プロシージャルダンジョン基底を流用し、A世界固有の部屋・演出・音響を追加。

## 4. プログレッション設計（レベルデザイン）

ゲーム全体の進行は、主人公のレベル帯と標的となる資本の規模に応じて大きく4つのフェーズに分かれます。

### 4.1. 序盤（Lv1-20）：逃亡と覚醒
- **目標**: ミダス商会の追手から逃亡し、スラム街でスキル開放戦線と合流する。
- **主要コンテンツ**:
  - **チュートリアル**: 《解析》の使い方の学習。敵の弱点を見抜き、ギリギリの戦闘をこなす。
  - **初捕食**: 追手の「下級スキルハンター」を倒し、初めて《喰らい》を成功させる（確定イベント）。《剣術》や《身体強化》などの基礎スキルを奪取。
  - **スラムでのサバイバル**: その辺のチンピラや野犬から「コモンスキル」を喰らい集め、合成の基礎を学ぶ。
- **ボス**: ミダス商会 スラム支店長（レアスキル《鋼鉄の皮膚》持ち）。喰らうことで序盤の耐久力が激増する。

### 4.2. 中盤（Lv21-50）：反撃と勢力拡大
- **目標**: 地方都市を解放し、ミダス商会を倒産に追い込む。さらに世界スキル銀行の地方支店を破壊する。
- **主要コンテンツ**:
  - **派閥戦争**: スキル開放戦線の部隊を率いて、ミダス商会の施設を襲撃。
  - **レアスキル争奪戦**: 「闇スキルブローカー」から情報を買い、賞金首や貴族を襲って強力なレアスキルをピンポイントで喰らいに行く。
  - **スキル合成実験**: 集めた多数のスキルを組み合わせ、自分だけの「壊れビルド」を構築する。
  - **従属スキル保有者の育成**: 倒した敵を空っぽにし、使い魔として再構成してパーティを組む。
- **ボス**: ミダス商会 CEO（ユニークスキル《黄金錬成》持ち）。

### 4.3. 終盤（Lv51-80）：神殺しと法則再編
- **目標**: 首都に乗り込み、世界スキル銀行本部を襲撃。マスタースキルを喰らい尽くす。
- **主要コンテンツ**:
  - **概念の柱との対話**: 9柱の神々（概念）にアクセスし、上位の「コンセプトスキル（概念スキル）」の試練に挑む。
  - **銀行防衛部隊との総力戦**: 銀行が雇う最強の「ユニークスキル保有者」たちとの連戦。敵もこちらのスキルを無効化・反射してくるため、《解析》によるリアルタイムなビルド組み換え（戦闘中の合成・破棄）が鍵となる。
  - **真エンド分岐**: マスタースキルを喰らった後、「自らが新たな神（総裁）となるか」「スキルシステムそのものを世界から消し去るか」の選択。
- **ラスボス**: 世界スキル銀行 頭取（マスタースキル《法則支配》持ち）。

### 4.4. 輪廻後（エンドコンテンツ）
- **目標**: より多くの概念喰い、別ルート・隠し要素の解放。
- **主要コンテンツ**:
  - **ニューゲーム+**: 強くてニューゲーム。前世のスキル資産を引き継ぎ。
  - **専用スキル《世界編集》の解放**: 周回特典。ドロップ率や敵の出現テーブル、さらにはNPCのセリフ（フラグ）すら改ざんできるようになるメタスキル。
  - **隠しボス**: 「初代スキルイーター（過去に銀行に挑んで敗れた者）」。主人公と同じ《解析》《喰らい》《合成》を極めた最強の同キャラ対決。

## 5. UI/UX デザイン方針

- **解析モード（スキャナーUI）**:
  戦闘中やフィールド探索時、ボタン一つで画面が「解析モード（マトリックスのようなコード視覚化状態）」に切り替わる。敵の頭上にスキルツリーのノードがホログラムのように浮かび上がり、喰らうべきターゲットが一目でわかるデザイン。
- **スキルツリー画面（星図UI）**:
  一般的な樹形図ではなく、「宇宙の星々（スキル）を線で結んでいく」広大な星図のようなUI。中央に《解析》があり、喰らったスキルが周囲に配置されていく。
- **ダークでリッチなビジュアル**:
  資本主義の退廃（サイバーパンク的なネオンとスラム）と、魔法ファンタジーが融合した「魔導スチームパンク・コーポレート」なアートスタイル。
