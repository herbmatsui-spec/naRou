# 提案3（洗練版）【メタシナリオ介入】「なろうテンプレ粉砕」プロシージャル・イベントシステム

## 0. エレベーターピッチ

本システムは、なろう系ファンタジーでおなじみの「無能追放」「婚約破棄」「ざまぁ」「横取り」といった物語的お約束（＝テンプレ・シナリオフラグ）を、**プレイヤーが「読者視点のメタ知識」で先回りし、破壊・収穫する**非同期介入ゲームプレイである。既存の `MetaAwarenessSystem`（原典閲覧 / Readers' Privilege）と `karma_system`、そして `skill_eater_*` 系の「スキル強奪」世界観を拡張し、1周目は「喰われる側」だった主人公が、周回を重ねて「テンプレそのものを市場として arbitrage（裁定取引）する存在」へと昇華する循環を提供する。

設計の根幹は「**作者（運命）が敷いたレールを、読者（プレイヤー）がハッキングする快感**」である。これは本作のコア体験「概念喰らい」の純粋なメタ展開であり、ナラティブとシステムが一致する稀有な構造になっている。

---

## 1. 三層ループ構造（デザインの脊柱）

システムは以下の3層から成る。これを分離することで、単なる「イベント選択肢」に陥らず、恒常的な遊びとして機能する。

- **L1・予兆層（Foresight）**：探索中に `MetaAwarenessSystem.trigger_flash_forward()` が「このNPCは〇〇ルートに乗っている」という**テンプレ・フラグの揺らぎ**を検出する。原典閲覧の `awareness_level` が高いほど、フラグの中身（未来分支）が深く読める。
- **L2・介入層（Intervention）**：プレイヤーは検出したテンプレに対し、定石とは逆の介入アクションを実行する。ここが本システムの主舞台。
- **L3・収穫層（Harvest）**：介入の成否と「破壊の完全性」に応じ、因果ポイント（`ReincarnationMetaState.total_karma_points`）や限定ユニークスキル、強奪スキルを獲得する。獲得した因果ポイントは既存の `GlobalRuleEngine.override_rule()` で世界法則を書き換える通貨にもなる。

この3層を「探索→判定→報酬」の小さなループにし、かつ周回（輪廻転生）ごとにL1の検出精度とL3の裁定幅が拡大するよう設計する。

## 2. 原典閲覧（リーダーズ・プリビレッジ）の拡張仕様

既存の `MetaAwarenessSystem` は「最悪の未来タイムライン」のみを返している。これを**テンプレ・フラグの多段階リーディング**に拡張する。

- **フラグ揺らぎの可視化**：NPCに `scenario_flags: dict[str, float]` を付与。`"expel"` `""betray""` `""credit_steal""` などのフラグがあり、値が 0.0〜1.0 で「そのテンプレに乗る確率」を示す。探索時に周囲NPCのフラグをスキャンし、閾値超えをハイライトする（既存サイバー義眼AR演出と親和）。
- **深度別リーディング（tiered peek）**：
  - Lv1（揺らぎ検知）：「この男、追放フラグ臭う」程度。
  - Lv2（分岐予測）：「追放される前にスキルを安く手放すタイミングが存在する」と取引窓口を提示。
  - Lv3（原典全開）：「この婚約破棄は実は公爵家の陰謀ルートで、破棄後にヒロインが死亡フラグを踏む」など、介入すべき正解手順まで示唆。
- **閲覧コスト**：原典閲覧は「メタ的覚醒」ゆえに代償を要する。1回の深読みにつき `karma_law_chaos` を微減（秩序から逸脱）させ、また「知りすぎた」分だけ `ReincarnationMetaState.unlocked_secrets` を蓄積。これが「世界にバレる」リスク（後述4・失敗）の種となる。

## 3. プロシージャル・テンプレイベント生成

イベントは手動配置ではなく、**テンプレ・アーキタイプ × 配置コンテキスト × 勢力**の組み合わせで自動生成する。

- **テンプレ・アーキタイプ（= 物語の型）**：追放／婚約破棄／横取り／裏切り／ざまぁ／天才差別／眷属化／転生者の成り上がり……などの「なろう的お約束」をデータ化。
- **コンテキスト**（重み付き抽選）：ダンジョン前哨基地・スラム・貴族社交界・ギルド支部・王都広場など。例えば「横取り貴族」は社交界で、「無能冒険者」はスラム/ギルドで出やすい。
- **勢力タグ**：既存 `relationships` の `OUTLAW`/`GUARD`/商人ギルド/貴族派閥などと結びつけ、介入が勢力ゲージにどう影響するか決定。

生成時は `(archetype, context, faction, difficulty)` のシードから、**「本来の定石展開（定形ルート）」と「プレイヤーが狙える裏口（exploit窓）」の両方**を算出する。定形ルートは `MetaAwarenessSystem.get_worst_future_timeline()` のようにテキスト化され、「介入しない場合の破滅／他所での収穫」として表示される。

## 4. 介入アクションの3階層（コア・ゲームプレイ）

介入は自由度とリスクに応じ3階層に分類する。浅いほど安全だが報酬も薄く、深いほど「テンプレの完全破壊」に近づく。

### T1・表面介入（Surface Maneuver）
テンプレの「結果」だけをハイジャックする。例：
- 無能追放フラグのNPCが追放前に売りに出すスキルを、**相場の1割で買い叩く**（先行収集）。
- 横取り貴族が手柄を横取りしようとする瞬間に、自分がすでに証拠を公開済みにし、手柄ごと「正当な功績」として横取り返しする。
- リスク：低。報酬：因果ポイント小＋金銭。

### T2・構造介入（Structural Hijack）
テンプレの「因果の順序」を書き換える。例：
- 婚約破棄の場で、破棄される側（ヒロイン）を先に「自ら婚約を解除する」よう仕向け、**破棄される側の自尊心フラグを逆転**させる。ざまぁが成立しなくなる。
- 裏切りを企む仲間を、裏切る前に「裏切りの証拠」を捏造・設置し、相手が裏切る前にこちらから追放/捕食する（先制喰い）。
- リスク：中（`karma_good_evil` の変動大）。報酬：因果ポイント中＋限定ユニークスキルの種。

### T3・存在介入（Ontological Severance）
そのテンプレ・アーキタイプそのものを「この世界から消滅」させる。例：
- 「ざまぁ」の型を持つ一連のイベントチェーンをすべて潰し、該当地域の `scenario_flags` の "ざまぁ" 重みを永久減衰させる。
- これは `GlobalRuleEngine.override_rule()` と接続し、「ざまぁ指数」「追放発生率」といった**世界パラメータそのもの**を書き換える（因果ポイント大消費）。
- リスク：高（「世界への露見度」急増）。報酬：因果ポイント大＋世界法則改変権＋周回の初期値優位。

## 5. テンプレ・カタログ（具体例）

| アーキタイプ | 定形ルート（放置時） | 狙える裏口（exploit） | 推奨階層 |
|---|---|---|---|
| 無能追放 | 才能なく追放→その後大物化 | 追放直前の安値スキル買い叩き／追放後に専属契約 | T1〜T2 |
| 婚約破棄 | ヒロイン辱められざまぁ | ヒロイン側からの先制破棄／真犯人（公爵）の露見 | T2 |
| 手柄横取り | 傲慢貴族が功績奪取 | 横取り貴族を罠へ誘導し合法的捕食 | T2〜T3 |
| 裏切り仲間 | パーティ内通敵 | 裏切り前の証拠捏造・先制喰い | T2 |
| 天才差別 | 実力者を環境が潰す | 差別構造そのものを買収・逆利用 | T3 |
| 眷属化 | 強者が配下を増殖 | 眷属化の儀式をハイジャックしこちらへ従属 | T2〜T3 |

各テンプレには「破壊完全性（0〜100%）」が定義され、完全破壊（100%）に近いほど報酬倍率が跳ね上がる。半端な介入（例：横取りは防いだが貴族は逃走）は完全性が低く、因果ポイントも端数のみ。

## 6. 評価・因果ポイント・報酬設計

### 判定式
介入スコアは以下で算出：
```
score = 破壊完全性 × 階層係数 × (1 + 露見ペナルティ逆数) − 失敗ペナルティ
```
- **階層係数**：T1=1.0, T2=2.5, T3=6.0
- **破壊完全性**：テンプレの定形ルートをどこまで潰したか（0.0〜1.0）。

### 報酬の3形態
1. **因果ポイント（Karuma Points）**：既存 `total_karma_points` に加算。周回の通貨かつ法則書き換え資源。
2. **限定ユニークスキル**：後述7。
3. **強奪スキル／アイテム**：既存 `skill_eater_bounty_system` の「スキル強奪」と接続。テンプレNPCが本来手にするはずだった「主人公補正スキル」を横取りできる（例：追放されるはずの無能冒険者が覚醒後に得る《逆境の覇気》を先取り）。

### 周回スケーリング
`SkillEaterReincarnationSystem` と連動し、1周目はT1〜T2主体、周回ごとに `awareness_level` と `total_karma_points` が引き継がれ、T3（世界法則改変）が現実的になる。また周回で乱獲したアーキタイプは「この世界のテンプレ供給が枯渇／変質」し（`apply_world_modifier` 的仕組み）、新たな亜種テンプレが生成されることで、周回ごとの新鮮さを担保する。

## 7. 限定ユニークスキル一覧（案）

テンプレ破壊の完全性に応じて解禁。いずれも「メタ的」な効果を持つ。

- **《ざまぁの極み》**：敵が「ざまぁ」を狙う行動をとった瞬間、その期待値を0にし、相手の自尊心に即死級の精神ダメージを与える。対テンプレ特効。
- **《追放者の意地》**：自らが不利な状況（HP低・包囲）に置かれたとき、逆に全ステータスとドロップ率が倍化。「無能追放」を逆手に取った自己強化。
- **《横取り還元》**：他人が得た功績・スキル・アイテムの所有権を、条件付きで強制的に自身へ再割り当てする（既存強奪システムのメタ上位版）。
- **《原典編集》**：一度読んだテンプレ・フラグを、その場で「別の定形ルート」へ書き換える（L3介入の常時化）。
- **《読者特権・外伝創生》**：破壊したテンプレを「自分だけのIF外伝」として保存し、任意の場面で召喚・再現できる（召喚ユニット化）。

これらは `skill_eater_registry` の `SkillTier` に `META_UNIQUE` 相当を追加して登録し、通常ドロップからは出現しない「介入専用」プールとする。

## 8. 失敗・反作用・リスク（重要）

快感だけではゲームにならない。以下の反作用で緊張を保つ。

- **露見度（Exposure）**：T3や深い原典閲覧は `unlocked_secrets` を蓄積させ、「世界の運命（作者）」にバレやすくなる。露見度が閾値を超えると、**運命の補正（テンプレがプレイヤーに対して先制攻撃・罠化）**が発生し、狙われる側が狙う側に回る。
- **因果の歪み**：T2以上の構造介入は `karma_good_evil` を大きく動かす。善悪の極端な偏りは、既存ガード追跡（`engine.py` の `karma > -30` ロジック）や勢力関係悪化を誘発。
- **テンプレの報復増幅**：一度破壊したアーキタイプは「学習」し、再生成時にプレイヤーへの耐性（介入窓の狭小化）を持つ。乱獲ほど難易度が上がる自然なインフレを作る。
- **介入失敗時**：テンプレが定形通り完遂され、しかもプレイヤーが「共犯者」として巻き込まれる（カルマ低下＋敵対勢力増）。「やらない方がマシ」になる失敗も許容する。

## 9. バランスと難易度曲線

- **発生頻度**：探索1区画あたり 0.3〜0.8 件のテンプレ揺らぎ。深い層（ダンジョン奥・王都）ほど高難度アーキタイプ。
- **取得成功の期待値**：T1=高（~85%）／T2=中（~55%）／T3=低（~30%だが報酬6倍）。浅く広くか深く狙うかのトレードオフ。
- **因果ポイント単価**：T1成功=50〜150P、T2=400〜900P、T3=2000〜5000P（完全性連動）。法則書き換え 1回=5000P 相当と照らし、数周でT3が狙える設計。
- **周回減衰**：同一アーキタイプの乱獲は単価を 0.7倍/周 ずつ減衰させ、多様なテンプレへの挑戦を誘う。

## 10. ナラティブ・世界観との整合

本作の世界はもともと「概念喰らい」「輪廻転生」「世界法則の書き換え」を含むメタfictionである。したがって「なろうテンプレは、この世界を書いた『上位の物語構造（作者／運命）』が仕込んだレール」という設定に落とし込む。プレイヤーは周回ごとに「読者」から「作者」へ立場が反転していく——これは `GlobalRuleEngine` の ROOT権限獲得と主題が一致する。最終的にプレイヤーは「テンプレを喰らう者」として、運命そのものを裁定取引する存在になる。

## 11. 実装マッピング（既存システム接点）

- **検出**：`MetaAwarenessSystem.trigger_flash_forward()` を拡張し、`scenario_flags` スキャンを追加。
- **因果**：`karma_system.KarmaData` に `exposure` 軸、`ReincarnationMetaState` に `devoured_template_counts` を追加。
- **報酬**：`skill_eater_bounty_system` の強奪フローを流用し、介入成功時に `stolen_skill` として付与。
- **法則書き換え**：T3成功時は `GlobalRuleEngine.override_rule(rule_name="template_weight_xxx", value=0.0, cost_type="KARMA")` を呼び出し、世界パラメータとして永続反映。
- **UI**：サイバー義眼AR演出（`emote_*`/`bookFlip*`）を流用し、フラグ揺らぎを画面端にオーバーレイ表示。

## 12. モチベーションと心理的報酬

このシステムが刺さるのは、「なろうを知っている読者」の「お約束への痛快な反逆欲」である。報酬は物量的なものだけでなく、**「作者の意図をハックした」というメタ的優越感**を中心的快楽に据える。完全性100%のテンプレ粉砕時には専用の「ざまぁ粉砕演出（glitch崩し＋原典破り演出）」を挟み、カタルシスを儀式化する。同時に、露見度という「バレる恐怖」がその快感を引き立てる緊張の対極を提供する。

## 13. 生成パイプラインの具体設計（Seed → Route → Exploit）

プロシージャル生成は以下の順で解決する。

1. **Seed 決定**：`(archetype, context, faction)` を重み付き抽選。コンテキスト別のアーキタイプ重み例：
   - スラム：`無能追放`(0.4) `裏切り仲間`(0.25) `手柄横取り`(0.2) `天才差別`(0.15)
   - 貴族社交界：`婚約破棄`(0.35) `手柄横取り`(0.3) `眷属化`(0.2) `天才差別`(0.15)
   - ダンジョン前哨：`裏切り仲間`(0.35) `無能追放`(0.3) `横取り`(0.2) `眷属化`(0.15)
2. **Route 算出**：定形ルートを `route_steps: list[FlagStep]` として展開。各ステップは `flag`, `turn`, `actor`, `on_fail`（放置時の結末）を持つ。
3. **Exploit 算出**：Route のうち「プレイヤーが裏口を突けるステップ」を `exploit_windows: list[Window]` として列挙。各窓は `req_skill/req_item`, `tier`, `base_success` を持つ。
4. **Difficulty**：`diff = Σ(exploit_window.base_success の逆数) × context_mod × loop_mod`。周回 `loop_count` が上がるほど `loop_mod` が緩和され、T3 へ到達しやすくなる。

これにより「同じテンプレでも出現場所で介入窓が変わる」という、探索地点ごとの戦術差が生まれる。

## 14. 階層別・意思決定ツリーの具体例（T2「婚約破棄」）

定形ルート：`[公開場で破棄宣言] → [ヒロイン屈辱] → [公爵が後ろで嗤う] → [ヒロイン死亡フラグ]`。

- **T1（表面）**：破棄式の直前にヒロインへ「逃亡用ポータル」を渡し、屈辱シーンをスキップ。完全性 40%。報酬 T1 相当。
- **T2（構造）**：破棄前に「公爵の陰謀証拠」をリークし、破棄の主導権をヒロインへ移譲（自ら解除）。完全性 80%。公爵の `scenario_flags["credit_steal"]` を反転し、こちらが公爵領を合法接收。
- **T3（存在）**：この社交界における「婚約破棄という型」そのものを `override_rule("break_engagement_rate", 0.0)` で枯渇。完全性 100%。報酬 ＋《原典編集》の種。

このように「どこまで深く切るか」がプレイヤーの戦略選択となる。

## 15. 報酬ティア表（完全性連動）

| 完全性 | 因果P倍率 | 追加報酬 |
|---|---|---|
| 0–39% | ×0.3 | 金銭のみ |
| 40–69% | ×1.0 | 因果P＋稀に強奪スキル |
| 70–89% | ×1.8 | 因果P＋限定ユニーク（種） |
| 90–99% | ×2.6 | 因果P＋限定ユニーク（完成） |
| 100% | ×4.0 | 因果P大＋世界法則改変権＋専用演出 |

完全性は「定形ルートの未潰しステップ数」で決まるため、プレイヤーは「全部潰すか、早払いで妥協するか」を常に判断する。

## 16. 実践プレイスルー（第2周目・スラム）

1. スラム探索中、`awareness_level=4` で「無能追放」フラグ 0.7 のNPCを検出。
2. 原典閲覧Lv3：`[追放前夜に《農耕神の加護》を二束三文で手放す]` という窓を特定。
3. T1介入：夜間に NPC へ交渉、相場1割でスキル購入。完全性 55%（追放自体は発生）。
4. 追放後、NPC を「専属契約者」として雇用（T2寄り）。完全性 78%。
5. 報酬：因果P 720、強奪スキル《農耕神の加護（下位）》。露見度微増。
6. 周回で `total_karma_points` 蓄積→のちT3で「無能追放」アーキタイプを地方ごと枯渇させる糧に。

## 17. データスキーマ例（YAML）

```yaml
template:
  id: expel_incompetent
  archetype: expel
  contexts: [slum, guild]
  faction_weight: { outlaw: 0.4, guild: 0.3 }
  route_steps:
    - { flag: sell_skill_cheap, turn: 2, actor: npc, on_fail: expelled }
    - { flag: rise_later,         turn: 8, actor: npc, on_fail: none }
  exploit_windows:
    - { id: buy_cheap,    tier: 1, req_gold: 200, base_success: 0.85 }
    - { id: exclusive_contract, tier: 2, req_skill: [negotiation], base_success: 0.55 }
  reward:
    karma_t1: 120
    karma_t2: 700
    stealable_skill: farming_blessing_minor
```

このスキーマを `data/templates/*.yaml` に置き、生成器が読み込むことで、新テンプレ追加がデータ駆動で行える。

## 18. 既存エンドゲーム（ボス・法則書き換え）とのシナジー

- T3 介入で得た「世界法則改変権」は、既存 `GlobalRuleEngine.override_rule()` をそのまま呼ぶため、ボス戦（`check_boss_meta_counter`）のメタ特効条件とも連動。例えば「横取り」アーキタイプを枯渇させると、横取り系ボスの《黄金錬成》即死術式が弱化する。
- `apply_world_modifier()` の要素暴落メカニズムをテンプレ版に拡張し、「乱獲したテンプレの供給単価低下／対抗テンプレ高騰」を再現。周回の経済循環と整合。

## 19. アンチパターン／設計上の罠

- **罠A・選択肢の形骸化**：介入を「A: 正攻法 / B: メタ破壊」の二択にすると、B一択ゲームになる。T1〜T3 の連続性と「完全性」のトレードオフで、浅い介入にも正当な理由を与える。
- **罠B・原典閲覧の無代償化**：閲覧にコスト（カルマ減／露見度）を課さないと、全テンプレを先読みして退屈になる。深度ごとの代償曲線を維持。
- **罠C・報酬のインフレ**：因果ポイント単価を固定すると、周回で桁違いに蓄積し法則書き換えが無価値に。周回減衰（§9）と `loop_mod` の緩和で釣り合いを取る。
- **罠D・メタの自己言及ループ**：テンプレ破壊自体が「なろう的」になる皮肉を避けるため、破壊は常に「別の物語の開拓」として描く（外伝創生スキル等）。

## 20. UX／読みやすさ設計（メタ閲覧UI）

- **フラグ揺らぎの視覚化**：サイバー義眼AR演出を流用し、NPC 頭上に「⚑追放 0.7」「⚑横取 0.4」の极小バッジを表示。濃淡で緊急度を表現。
- **原典閲覧モード**：Lv3 時のみ、介入窓を「ハイライトされたIFルート」として画面下部にタイムライン表示。ただし閲覧中は時間が進む（代償のリアルタイム化）で緊張を持たせる。
- **完全性ゲージ**：介入実行時に「テンプレ粉砕率」をくるくる回るグリッチ演出で提示し、100% で専用クラック演出（既存 `bookFlip*`/`metalPot*` を拡張）。

## 21. まとめ

「メタシナリオ介入」は、本作の既存メタfiction基盤（原典閲覧・因果・スキル強奪・輪廻転生）を最大限に活用し、なろうテンプレを**市場・罠・収穫対象**へと転換するシステムである。3層ループと3階層介入、そして露見度というリスク軸により、単なるギミック以上の恒久的遊びと、周回ごとの成長実感を両立する。これは「概念喰らい」の精神を物語構造そのものへ拡張する、本作独自の差別化要素になる。
