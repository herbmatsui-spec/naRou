# 🎮 Design A: NPCダイアログ仕様（Ver 1.0）

本ドキュメントは、「スキル喰いの異世界倒産」における主要NPCのダイアログスクリプトを定義します。
ゲーム内の好感度（忠誠度／敵対度）や、主人公のスキル階級、ストーリー進行度（フェーズ）によって台詞が動的に変化するシステムを想定しています。

---

## 1. ダイアログデータ構造 (JSON想定)

```json
{
  "npc_id": "midas_ceo",
  "name": "ドン・ミダス",
  "faction": "midas_holding",
  "dialogues": [
    {
      "condition": "phase == 1 && player_tier == 'slave'",
      "text": "ゴミにはゴミの掃き溜めがお似合いだ。《解析》などという無価値なスキルしか持たぬ貴様は、我が社の便所掃除すら務まらん。とっとと失せろ。"
    }
  ]
}
```

## 2. 主要キャラクターのダイアログ展開

### 2.1. ミダス商会 関連NPC

#### **人事部長 ガルシア（序盤のチュートリアル・解雇宣告者）**
- **解雇時（フェーズ1開始）**:
  「はぁ……今年の新人ガチャは大外れか。おい、そこのお前だ。適性検査の結果が出たぞ。所持スキル《解析》のみ、だと？ なんだそのハズレスキルは！ 物の構造を見るだけなら鑑定士の足元にも及ばん！ 貴様のような無能に払う給料はない、即刻クビだ。警備員！ このゴミをスラム街に放り出してこい！」
- **スラム街で主人公がスキル喰いをした直後（通信越し）**:
  「……何？ 下級ハンターとの通信が途絶えただと？ あのゴミが反撃したとでも言うのか？ ええい、たかがノースキルの分際で！ 予備のハンター部隊を向けろ。生け捕りにする必要はない、四肢をもいでスキルカードを剥ぎ取ってこい！」

#### **ミダス商会 CEO ドン・ミダス（中盤のボス）**
- **対峙時（フェーズ2 決戦前）**:
  「ほう、あの時スラムに捨てたゴミが、まさか我が社の扉を蹴破ってくるとはな。『スキル喰い』……忌まわしき都市伝説が実在したというわけか。だが、いくら他人のゴミスキルをかき集めようと、資本の暴力には勝てんのだよ！ 私の《黄金錬成》で、貴様を純金の延べ棒に変えて、私のデスクの文鎮にしてやろう！」
- **戦闘中（HP50%以下）**:
  「ば、馬鹿な！ なぜ私のスキルの動きが読まれている！？ 貴様、ただの《解析》ではないのか！？」
- **撃破・捕食時**:
  「や、やめろ……！ 私からスキルを奪うな！ スキルが、私の資本が、私の全てがぁあああ！！」

### 2.2. スキル開放戦線（レジスタンス） 関連NPC

#### **リーダー カミラ（ユニークスキル《不屈の解放》所持）**
- **初対面時（スラム街）**:
  「あんた、ただの浮浪者じゃないね。その目……ミダスに全てを奪われた人間の目だ。私はカミラ。スキル開放戦線のリーダーだ。あんたのその特異な力、私たちの『革命』に貸してくれないか？」
- **好感度【低】 / アジト帰還時**:
  「戻ったか。休んだらすぐに次の任務に出てもらう。我々に立ち止まっている暇はないんだ。」
- **好感度【高】 / アジト帰還時**:
  「お疲れ様。あんたが持ち帰ってくれるスキルのおかげで、戦線の皆がどんどん強くなっている。……ふふ、あんたを見ていると、本当に世界を変えられるような気がしてくるよ。」
- **フェーズ3開始時（世界スキル銀行襲撃前）**:
  「いよいよだね。資本主義のバベルの塔……世界スキル銀行。相手は神にも等しい力を持つ連中だ。だけど、私たちにはあんたがいる。さあ、このクソみたいな格差社会に、引導を渡してやろう！」

#### **武器商人（裏ブローカー） ザック**
- **通常利用時**:
  「ヘヘッ、いらっしゃい。今日は何をお探しで？ ミダスの横流し品から、銀行からちょろまかしたヤバいブツまで、金（アルド）さえ払えば何でも揃えてやるよ。」
- **裏情報購入時（レアスキル持ちの座標提示）**:
  「……おっと、こいつはとびきりの情報だぜ。第4区画に、銀行の『お偉いさん』がお忍びで来てるらしい。護衛は薄い。あいつの持つ《思考加速》、あんたなら……『美味しく』いただけるんじゃないか？」

### 2.3. 世界スキル銀行（最終勢力） 関連NPC

#### **監査官 執行者オメガ**
- **初遭遇時（フェーズ2〜3）**:
  「警告。特異個体『スキルイーター』の存在を検知。これより、世界スキル銀行法・第4条に基づき、貴殿の資産（スキル）および存在そのものを強制差し押さえ（消去）する。」
- **戦闘中**:
  「エラー。対象の解析能力が当方のアルゴリズムを上回っています。論理崩壊。……シ、システム、復旧ヲ――」

#### **頭取（真のボス・マスタースキル所持）**
- **最終決戦前**:
  「……よくぞここまで辿り着いた、イレギュラーよ。だが、貴様は勘違いをしている。このスキル資本主義は、人間という愚かなリソースを最も効率的に管理・最適化するための完璧なシステムなのだ。スキルを喰らうなどというバグ技で、世界の真理（マスタースキル）に触れられると思うな。」
- **最終決戦中（主人公がスキルを合成して対抗した時）**:
  「な、なんだそのスキルは！？ 私のデータベースに存在しない概念！？ 貴様、世界の法則（ソースコード）を直接書き換えようというのか！！」
- **真エンディング（主人公に敗北）**:
  「見事だ……。法則は、貴様という新たな神（管理者）に譲渡された……。さあ、選ぶがいい……。この世界を、どうアップデートするのかを……。」

## 3. 従属スキル保有者（ペット／パーティメンバー）ダイアログ

敵を「空っぽ」にした後、スキルを移植して従属させたキャラクターの汎用セリフ。

- **人格初期化直後（スキル移植前）**:
  「……ア……。ワタシハ……ダレ……？ カラッポ……。」
- **戦闘用スキル移植後（従属状態）**:
  「マスター、命令ヲ。ワタシノ、スキルハ、アナタノタメニ。」
- **忠誠度MAX（育成完了時）**:
  「あなたの与えてくれたこの力が、今の私の『心』です。マスター、最後までお供させてください。」
