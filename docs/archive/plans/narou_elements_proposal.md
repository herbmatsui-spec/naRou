# Elona × なろう系要素 統合提案書

## 概要
Elonaの「自由度」「カオス」「多様な成長」という核心に、**なろう系（異世界転生・チート・ステータス画面・スキル習得・ギルド・称号）** の要素を9つ融合させ、より中毒性の高い「自分だけの最強ビルド」体験を実現する。

---

## 1. 【スキルツリー＆ジョブシステム】〜「気づけば最強ジョブマスター」〜

### コンセプト
Elonaのスキル潜在能力システムを、**ジョブ（職業）ツリー**へ拡張。レベルアップ時に「ジョブポイント（JP）」を獲得し、ツリー上で自由に解放。

### 実装詳細
| 要素 | 仕様 |
|------|------|
| **ジョブツリー** | `warrior → swordmaster / paladin / berserker` 等の分岐 |
| **JP獲得** | レベルアップ毎 +1JP、クエスト達成でボーナス |
| **パッシブ/アクティブ** | パッシブ常時発動、アクティブはMP/スタミナ消費で発動 |
| **マスターボーナス** | 1ジョブ全解放で「マスター称号」+ 固有スキル獲得 |

### 既存連携
- `entity.py` の `skills` 辞書を拡張し `job_tree: Dict[str, JobNode]` 追加
- `gain_exp()` 内で JP 付与
- `advanced_systems.py` に `JobSystem` クラス新設

### なろう味演出
> 「気づけば《剣聖》《大賢者》《神速の弓使い》を同時にマスターしていた件」

---

## 2. 【チート級ユニークスキル「鑑定眼」】〜「これ、実は神器でした」〜

### コンセプト
アイテムの**真の性能・隠しエンチャント・由来ストーリー**を可視化。Elonaの「未鑑定」を「鑑定スキルLvで段階的開示」へ進化。

### 実装詳細
| Lv | 開示内容 |
|----|----------|
| 1 | 基本性能（攻撃力・防御力・重量） |
| 5 | 素材・品質・エンチャント1つ |
| 10 | 全エンチャント・呪い有無 |
| 15 | **由来ストーリー**（「古の英雄が竜を討った剣」等） |
| 20 | **隠しパラメータ**（クリ率補正・セット効果・成長余地） |

### 既存連携
- `item_system.py` の `Item` に `hidden_enchants`, `lore_text`, `growth_potential` 追加
- `rich_content.py` に鑑定結果用ロアテキスト追加
- `systems.py` に `AppraisalSystem` 追加

### なろう味演出
> 「【鑑定眼Lv20】『ゴミに見えたこの石、実は《世界樹の欠片》だった件』」

## 3. 【称号・二つ名システム】〜「異名は『災厄を招く冒険者』」〜

### コンセプト
行動実績に応じて**称号（二つ名）**が自動付与。ステータス画面・会話・ログに表示され、微小なボーナスを付与。

### 実装詳細
| 称号例 | 条件 | 効果 |
|--------|------|------|
| 《初心者殺し》 | Lv1〜5の敵を100体討伐 | 同レベル帯へのダメージ+5% |
| 《エーテル耐性》 | エーテル病ステージ3到達 | エーテル病進行-20% |
| 《神の愛し子》 | 信仰度1000達成 | 祈り効果+50% |
| 《貧乏神の友》 | 所持金0で100ターン生存 | ドロップ率+10% |
| 《最速の配達人》 | クエストを制限ターン内クリア×10 | 移動速度+5 |

### 既存連携
- `entity.py` に `titles: List[Title]` 追加
- `game.py` の各種イベント（討伐・クエスト・信仰・所持金）で判定
- `render_all()` ステータス画面に称号欄追加

### なろう味演出
> 「気づけば二つ名が『《竜殺し》《神代の魔導師》《世界を救った凡人》』になっていた」

## 4. 【ギルド・派閥・ランキングシステム】〜「無名からギルドマスターへ」〜

### コンセプト
冒険者ギルド・商人ギルド・盗賊ギルド・魔術師協会等の**派閥**に所属し、貢献度でランクアップ。専用クエスト・ショップ・スキル解放。

### 実装詳細
| 派閥 | ランク | 解放内容 |
|------|--------|----------|
| 冒険者ギルド | 銅→銀→金→白金→英雄 | 依頼報酬UP・専用装備・転職許可 |
| 商人ギルド | 見習い→行商人→商会主→大商人 | 売値UP・希少品取扱・投資機能 |
| 盗賊ギルド | スリ→暗殺者→首領 | 窃盗成功率UP・闇市場・毒スキル |
| 魔術師協会 | 見習い→魔導士→大賢者→賢者の塔主 | 高位魔法・魔法道具作成・マナ効率UP |

### 既存連携
- `systems.py` に `FactionSystem` 拡張（既存FACTION_*を活用）
- `rich_content.py` にギルドNPC・専用クエスト追加
- `advanced_systems.py` に `GuildRank` クラス新設

### なろう味演出
> 「元引きこもり、気づけば《冒険者ギルド最年少マスター》になってた」

## 5. 【転生・ニューゲームプラス（輪廻）】〜「前世の記憶と共に、再び」〜

### コンセプト
特定条件（Lv50到達・全ジョブマスター・真ボス討伐等）で**輪廻転生**可能。前世の「魂の刻印」を継承し、より強く・速く育成。

### 実装詳細
| 継承要素 | 内容 |
|----------|------|
| **魂の刻印** | 最大3つ選択（ステータス+10%、スキルLv引継ぎ、所持金10%等） |
| **輪廻回数** | 表示用カウンタ（1周目・2周目…） |
| **隠し要素解放** | 2周目: 隠しダンジョン、3周目: 隠しジョブ、5周目: 真エンド |
| **難易度スケール** | 周回毎に敵強化・報酬UP・新規イベント発生 |

### 既存連携
- `advanced_systems.py` の `SaveSystem` に輪廻データ追加
- `game.py` の `Engine.__init__` で輪廻ボーナス適用
- `entity.py` に `reincarnation_count`, `soul_marks` 追加

### なろう味演出
> 「10周目、《全知全能の賢者》として世界を救うのは今日で最後だ」

## 6. 【スキル合成・進化システム】〜「《火球》+《風》=《爆炎竜巻》」〜

### 実装詳細
| ベースA | ベースB | 結果スキル | 効果 |
|---------|---------|------------|------|
| 火球術 | 風魔法 | 爆炎竜巻 | 範囲+継続燃焼+ノックバック |
| 治癒魔法 | 解剖学 | 外科手術 | HP全快+状態異常全回復+一時的能力上昇 |
| 窃盗 | 回避 | 影走り | 移動不可視+背後攻撃必中+アイテム強奪 |
| 採掘 | 鍛冶 | 鉱脈見極め | 採掘時レアドロップ率UP+即座に装備可能な武器生成 |

### 既存連携
- `entity.py` の `gain_skill_exp()` で合成条件チェック
- `advanced_systems.py` に `SkillFusionSystem` 新設
- `systems.py` の `CombatSystem` に合成スキル用エフェクト追加

### なろう味演出
> 「《鑑定》×《解析》=《真実の眼》——世界の全てがデータに見える」

## 7. 【ペット・使い魔・眷属の「契約・進化・融合」】〜「スライムが竜になった」〜

### コンセプト
ペット（シエル等）との**契約深度**で進化分岐。複数ペットを「融合」させ新種族創出。ElonaのペットAI・遺伝子合成を劇的に拡張。

### 実装詳細
| 契約段階 | 条件 | 変化 |
|----------|------|------|
| 従者 | 好感度50 | 基本AI・装備共有 |
| 契約獣 | 好感度100+クエスト | 専用スキル・進化分岐選択 |
| 眷属 | 好感度200+儀式アイテム | **種族変異**（スライム→竜等）・固有究極技 |
| 融合体 | 眷属2体+禁忌の儀式 | **新種族**・両親のスキル継承・見た目合成 |

### 既存連携
- `entity.py` の `affection`, `gene_skills` を拡張
- `advanced_systems.py` に `ContractSystem`, `FusionSystem` 新設
- `rich_content.py` に進化分岐ツリー・融合レシピ追加

### なろう味演出
> 「妹分シエル、気づけば《五頭竜の巫女》になってた件について」

## 8. 【ダンジョン・ワールド「自動生成ストーリーテラー」】〜「このダンジョン、俺のせいで魔王城になった」〜

### コンセプト
プレイヤーの行動履歴（倒した敵・使ったスキル・選んだ選択肢）を学習し、**そのプレイヤー専用のダンジョン・ボス・イベント**をプロシージャル生成。

### 実装詳細
| 入力データ | 生成への影響 |
|------------|--------------|
| よく使う属性 | 弱点属性の敵・装備を配置（対策必須） |
| よく倒す敵種 | その天敵・カウンター種を出現 |
| 選択した会話 | NPCの態度・派閥関係が変化 |
| 取得した称号 | 称号に対応した隠し部屋・試練出現 |
| 輪廻回数 | 過去周回の「影」ボスが出現 |

### 既存連携
- `map_engine.py` の `generate_dungeon()` に履歴ベース生成ロジック追加
- `game.py` に `StoryTeller` クラス新設（行動ログ蓄積・分析）
- `advanced_systems.py` のセーブデータに履歴サマリ保存

### なろう味演出
> 「俺が火魔法ばかり使ってたら、ダンジョン最深部に《氷結の魔王》が待ち構えていた」

## 9. 【実績・トロフィー・「やり込み可視化」】〜「プレイ時間3000時間、全実績解除」〜

### コンセプト
Steam実績ライクな**ゲーム内実績システム**。達成で「称号」「スキン」「便利機能」「裏設定資料」が解放。やり込みの動機付け・可視化。

### 実装詳細
| カテゴリ | 実績例 | 報酬 |
|----------|--------|------|
| 戦闘 | 「初陣」「百人斬り」「竜殺し」「神殺し」 | 称号・武器スキン |
| 探索 | 「全マップ踏破」「秘密の部屋発見×50」「最深部到達」 | ミニマップ機能拡張・透視リング |
| 生活 | 「料理マスター」「釣り名人」「栽培王」「鍛冶神」 | 専用レシピ・黄金道具 |
| 変態 | 「全アイテム食べた」「裸でボス撃破」「Lv1でクリア」「全NPCと会話」 | 裏設定資料・開発者モード |

### 既存連携
- `advanced_systems.py` に `AchievementSystem` 新設
- `game.py` の各所で `achievement.check(event_type, data)` 呼び出し
- `render_all()` に実績画面（ゲームステート追加）実装

### なろう味演出
> 「実績『《神をも超えた男》』解除——君の冒険は、もはや伝説だ」

## 技術的共通基盤（先行実装推奨）

1. **`data/narou_definitions.yaml`** — 全なろう要素のマスターデータ（ジョブツリー・称号条件・合成レシピ・実績定義等）を外部化
2. **`narou_system.py`** — 共通基盤クラス（`NarouEventBus`, `ConditionChecker`, `RewardGrantor`）
3. **`save_narou.py`** — 輪廻・実績・履歴データのセーブ/ロード拡張
