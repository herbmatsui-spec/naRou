# フェーズ4：没入感の深化（ポリッシュ） - 詳細実装計画書

## 🎯 目的
視覚・聴覚的な演出を強化し、プレイヤーが「生きている世界」にいると感じさせるディテールを追求する。

---

## 🛠 7. 動的サウンドスケープの実装

### 概要
単なるSEの再生から、環境や状況に連動して変化する「音の風景」へと進化させる。

### 📝 詳細ステップ (低性能LLM向け小分割)

#### ステップ 7.1: BGM管理システムの拡張
- [ ] `sound_manager.py` に `BGMManager` クラスを実装する。
- [ ] `play_bgm(track_id, fade_in=True)` メソッドを追加し、現在の曲から次の曲へ滑らかに切り替える（クロスフェード）機能を実装する。
- [ ] `data/audio_config.yaml` を作成し、場所（街、森、地下）とBGM IDの紐付けを定義する。

#### ステップ 7.2: 環境音（アンビエント）レイヤーの導入
- [ ] `sound_manager.py` に `AmbientLayer` クラスを実装する。
- [ ] BGMとは別に、ループ再生される環境音（例：風の音、洞窟の滴り、街の喧騒）を管理する。
- [ ] プレイヤーの現在地（`GameMap` のタイル種類や階層）に応じて、再生する環境音を動的に切り替える。

#### ステップ 7.3: 状況連動型サウンドエフェクト
- [ ] 戦闘中のHP低下時に、BGMのテンポを上げるか、緊張感のある曲に切り替えるトリガーを実装する。
- [ ] 重要なアイテム入手時に、専用のファンファーレをBGMに重ねて再生する。

---

## 🛠 8. 世界の変化の可視化

### 概要
プレイヤーの視界の外で起きている出来事を適切に伝え、「世界が自分以外にも動いている」感覚を演出する。

### 📝 詳細ステップ (低性能LLM向け小分割)

#### ステップ 8.1: 世界イベントログの生成
- [ ] `world_state_system.py` に `generate_world_news()` メソッドを実装する。
- [ ] ターン経過や特定のタイミングで、「〇〇（NPC）が△△（モンスター）を討伐した」「〇〇の街で祭りが始まった」などのニュースをランダムに生成する。
- [ ] 生成されたニュースを `MessageLog` に `INFO` レベルで挿入する。

#### ステップ 8.2: プレイヤー行動の反響（エコー）
- [ ] プレイヤーが特定の派閥のクエストを完了した際、後日、別のNPCから「〇〇さんが助けてくれたらしいな」という噂話を聞くダイアログを実装する。
- [ ] `relationship_system.py` と連動し、好感度が上がったNPCが、プレイヤーの不在時に他のNPCに好意的なことを話すイベントを生成する。

#### ステップ 8.3: 環境変化の視覚的通知
- [ ] 世界イベント（例：戦争の激化）が発生した際、`web_game_client.html` のステータスバーに小さなアイコンや警告文を表示する。
- [ ] 季節や天候の変化を `MessageLog` に「風が冷たくなってきた...」のように情緒的に出力する。

---

## 🛠 9. リソース最適化とパフォーマンス改善

### 概要
データ量が増大しても快適に動作し続けるよう、内部的なデータ処理を効率化する。

### 📝 詳細ステップ (低性能LLM向け小分割)

#### ステップ 9.1: YAMLデータキャッシュ機構の実装
- [ ] `config_manager.py` に `DataCache` クラスを実装する。
- [ ] 一度ロードしたYAMLデータをメモリ上に保持し、2回目以降のアクセスを高速化する。
- [ ] `get_data(file_path)` メソッドを通じて、キャッシュがあればそれを返し、なければロードしてキャッシュに保存する。

#### ステップ 9.2: 非同期ロードの導入（擬似的な実装）
- [ ] `web_server.py` と `web_game_client.html` の間で、大きなデータの転送を分割して行う仕組みを検討する。
- [ ] シーン遷移時に「ロード中...」のインジケーターを表示し、バックグラウンドでデータを準備する。

#### ステップ 9.3: メモリリークの調査と修正
- [ ] `save_system.py` や `Engine` で、不要になったオブジェクト（古いイベント、使い終わった一時的なリスト）が適切に破棄されているか確認する。
- [ ] `gc.collect()` を適切なタイミング（例：階層移動時）で呼び出し、メモリを解放する。

#### ステップ 9.4: 最終パフォーマンス検証
- [ ] 大量のアイテムやNPCを配置した状態で、1ターンの処理時間（Tick）が許容範囲内であることを確認する。
- [ ] `web_game_client.html` の描画更新頻度を最適化し、CPU負荷を軽減する。
