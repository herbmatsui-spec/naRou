# 視覚的報酬最大化のための統合テスト・検証計画

## 1. 検証目的
本プロジェクトで実装した「偏執的なグラフィック演出」が、すなわち9つの視覚的強化項目が、プレイヤーに十分な視覚的快感（Visual Reward）を提供しているか、およびシステム的な競合が発生していないかを検証する。

## 2. テストケース・検証項目

### A. 戦闘インパクト (Combat Impact)
- [ ] **ヒットストップ & 衝撃波**:
    - クリティカルヒット時に画面が一瞬停止し、白い衝撃波が放射状に広がるか。
    - 連続攻撃時にヒットストップが重なり、不自然なラグにならないか。
- [ ] **NPC感情パーティクル**:
    - 攻撃時(💢)、会話時(❤️/❓)、ダメージ時(💧)に適切な文字パーティクルが放出されるか。

### B. 魔法・スキル演出 (Magic & Skill FX)
- [ ] **動的魔方陣**:
    - 詠唱開始から完了まで、足元に回転する幾何学模様が表示され、完了時に輝きが増すか。
    - プレイヤーの移動に合わせて魔方陣が追従するか。
- [ ] **次元突破演出 (Dimension-break)**:
    - スキル覚醒時に画面中央から放射状のグリッチが発生し、色彩反転が明滅するか。
    - 演出終了後、スムーズに通常画面に戻るか。

### C. 環境・探索体験 (Environmental Immersion)
- [ ] **バイオーム・ライティング**:
    - 森(緑)、洞窟(青)、溶岩(赤)のエリアに移動した際、環境光（Ambient Color）が自然に変化するか。
    - 動的光源（松明など）と環境光が正しく加算合成されているか。
- [ ] **アンビエント・レイヤー**:
    - 3層の視差パーティクルが異なる速度で流れ、奥行き感があるか。
    - 精神状態(SAN値)低下時に、霧の色味が不気味に変化するか。
- [ ] **アーティファクト発光**:
    - レアアイテムの周囲にゴッドレイ（十字光）と浮遊粒子が表示されるか。

### D. UI/UX リッチ化 (UI Richness)
- [ ] **ダイナミック・オーラ**:
    - 高HP時に黄金の粒子が画面に散布され、「無敵感」を演出できているか。
- [ ] **エネルギー回路ビジュアライザー**:
    - スキルツリーの習得済み項目に脈動するエフェクト(⚡/✨)が表示されるか。
    - 背景に流れる回路パターンがスムーズにアニメーションしているか。

## 3. パフォーマンス・安定性検証
- [ ] **FPS低下の確認**: 全てのFXを同時に発生させた際（例：次元突破中に魔法を詠唱し、周囲にレアアイテムがある状態）、描画速度が著しく低下しないか。
- [ ] **色の破綻**: RGB加算合成により、色が白飛びしすぎて視認性が損なわれていないか。

## 4. 最終評価基準
- **視覚的快感**: 「単なる文字の入れ替え」ではなく、「世界が動いている」と感じられるか。
- **一貫性**: 全ての演出が「ダークファンタジー・ローグライク」という世界観に沿っているか。
