# ゲーム完成度向上ロードマップ (Quality Enhancement Roadmap)

本計画は、新機能の追加ではなく、既存システムの統合、安定化、およびユーザー体験（UX）の向上に特化したものです。

## 🛠 全体戦略
「機能の量」から「体験の質」へシフトし、プレイヤーが迷わず、ストレスなく、没入してプレイできる環境を構築します。

---

## 📅 フェーズ別実装計画

### フェーズ1：UX基盤の強化 (最優先)
**目的: プレイヤーの離脱を防ぎ、ゲームへの導入をスムーズにする**

- [ ] **1. インタラクティブ・チュートリアルの実装**
    - `HelpSystem` の拡張：コンテキスト依存型ガイドの導入。
    - 特定のトリガー（例：初めてのスキル合成、転生後の初回起動）でのポップアップ表示。
- [ ] **2. UI/UXの視認性とフィードバックの改善**
    - `web_game_client.html` の通知システムの強化（重要イベントの強調表示）。
    - `ui_fx_systems.py` を活用した視覚的フィードバック（画面揺れ、強調エフェクト）の追加。

### フェーズ2：安定性と整合性の確保
**目的: 長期プレイに耐えうる堅牢なシステムを構築する**

- [ ] **3. ゲームバランスの自動検証システムの構築**
    - `balance_sim.py` の再実装と強化。
    - 戦闘シミュレーションによる異常値（オーバーパワー/詰み）の自動検出。
- [ ] **4. セーブデータの堅牢化**
    - `save_system.py` へのチェックサム導入と整合性検証。
    - 自動バックアップ（ローテーション保存）の実装。
- [ ] **5. 体系的なエラーハンドリングの導入**
    - 全システム共通の例外クラス定義。
    - ユーザー向けエラーログのゲーム内表示と、安全な状態復帰メカニズムの実装。

### フェーズ3：アーキテクチャの洗練
**目的: 予期せぬバグを排除し、開発・拡張効率を上げる**

- [ ] **6. 状態遷移（ステートマシン）の厳格化**
    - `game.py` の `Engine` に明示的なステート管理を導入。
    - 状態に応じた入力制限（例：ダイアログ中は移動不可）の徹底。

### フェーズ4：没入感の深化（ポリッシュ）
**目的: 「ゲームとしての完成度」を極め、世界観を演出する**

- [ ] **7. 動的サウンドスケープの実装**
    - `sound_manager.py` の拡張：環境に応じたBGMのシームレスな遷移。
    - 環境音（アンビエント）のレイヤー実装。
- [ ] **8. 世界の変化の可視化**
    - 世界イベント（NPCの行動結果など）を `MessageLog` に統合。
    - プレイヤーの行動が世界に影響を与えたことを示す通知の強化。
- [ ] **9. リソース最適化とパフォーマンス改善**
    - YAMLデータのキャッシュ機構の導入。
    - 非同期ロードによるシーン遷移の高速化。

---

## 📈 期待される成果
- **ユーザー体験:** 複雑なシステムへの理解度が向上し、プレイの快感が増す。
- **安定性:** セーブデータ破損や予期せぬクラッシュが激減する。
- **品質:** 単なる「機能の集合体」から、洗練された「一つのゲーム作品」へと昇華される。
