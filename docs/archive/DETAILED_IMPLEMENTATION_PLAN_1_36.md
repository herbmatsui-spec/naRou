# タイルセット・アセットパイプライン実装計画書（詳細版：ステップ1-36）

## 概要
この計画書は、エミjiベースのレンダリングからプロフェッショナルなピクセルアート（16x16/32x32）への移行を、36個の小さなステップに分割して詳細に説明します。Tiled Map Editorサポート、アセットパイプライン自動化、および適切なタイルIDから画像へのマッピングを含みます。

## 前提条件
- Python 3.8以上
- Pillowライブラリ（画像処理用）
- 既存のnaRouプロジェクト環境
- Tiled Map Editor（マップ作成用、オプション）

### フェーズ1: 基盤構築（ステップ7-15）

**ステップ7: アセットディレクトリ構造を作成**
- assets/tiles/ディレクトリを作成
- 16x16と32x32のサブディレクトリを作成
- 各サイズでterrain, objects, entities, effectsサブディレクトリを作成

**ステップ8: 初期のプレースホルダー画像を生成**
- 16x16サイズで基本的なタイル画像を作成（色付きプレースホルダー）
- 32x32サイズでも同様にプレースホルダー画像を作成
- タイプ別に色を分ける（壁: 茶色、床: 緑など）

**ステップ9: tileset_def.jsonの基本構造を作成**
- JSONファイルの基本フォーマットを定義
- versionとtile_sizeフィールドを設定
- 初期のタイル定義スケルトンを作成

**ステップ10: 基本タイル定義を追加（静的タイル）**
- TILE_WALL: terrain/wall_dungeon.png
- TILE_FLOOR: terrain/floor_dungeon.png
- TILE_STAIRS_DOWN: terrain/stairs_down.png
- TILE_STAIRS_UP: terrain/stairs_up.png
- TILE_WATER: terrain/water.png
- TILE_TRAP: terrain/trap.png
- 各定義にファイルパスと基本属性を設定

**ステップ11: エンティティとアイテムのタイル定義を追加**
- PLAYER, PET, ENEMY_GOBLINなどのエンティティタイル
- ITEM_POTION, ITEM_WEAPON, ITEM_ARMOR, ITEM_GOLDなどのアイテムタイル
- DECOR_TORCH, DECOR_BLOOD, EFFECT_MAGICなどのエフェクトタイル
- アニメーションと方向性の情報を追加

**ステップ12: バリアントとアニメーション情報を追加**
- TILE_WALLとTILE_FLOORにvariants: 4, 8を設定（オートタイル用）
- アニメーションタイルにframesとfpsを設定
- タイルごとに必要な属性（variant_width, frame_widthなど）を定義

**ステップ13: TileRegistryクラスの基本構造を実装**
- map_engine.pyにTileRegistryクラスを追加
- __init__メソッドでJSONファイルを読み込む機能を実装
- ファイルが存在しない場合のフォールバック定義を用意

**ステップ14: UVマッピング機能を実装**
- get_uvメソッドを実装（tile_id, variant, scaleからUV座標を取得）
- フォールバックメカニズム（プロシージャル生成）を実装
- アニメーションフレーム取得のためのget_animation_frameメソッドを実装

**ステップ15: グローバルTileRegistryインスタンスを作成**
- ファイルの最後にTILE_REGISTRY = TileRegistry()を追加
- モジュールインポート時に自動初期化されるように設定
- 初期動作をテストする簡単なスクリプトを作成

**ステップ21: RenderSystemにアトラス読み込み機能を追加**

**ステップ22: ピクセルアートモードのレンダリングロジックを実装**

**ステップ24: 探索済みタイルの描画を実装**
- 探索済みだが不可視のタイルに対する描画ロジックを追加
- 暗めの色調整またはアルファブレンドで探索済み状態を表現
- エミジーモードとピクセルアートモードの両方をサポート**

- game.pyのEngine.updateメソッドを修正
- ゲームマップのupdate_animationsメソッドを呼び出す行を追加

**ステップ28: アニメーションタイルの初期化ロジックを追加**

**ステップ29: オートタイル/バリアント計算機能を実装**

## 成功基準

全ステップ完了後の達成目標:
- [ ] ゲームがエミjiモード（use_pixel_art=False）で正常に動作
- [ ] ゲームがピクセルアートモード（use_pixel_art=True）で正常に動作
- [ ] アニメーションタイル（水、階段、罠）が正しくアニメーション
- [ ] オートタイリングが機能し、シームレスな壁/床遷移を生成
- [ ] Tiled Map Editorで作成したマップが正しく読み込まれ表示
- [ ] アセットパイプラインがmake assetsで正常に実行
- [ ] パフォーマンスに顕著な劣化がないこと（FPS 5%以内の変化）
- [ ] 後方互換性が完全に維持されていること

## 注意事項

- 各ステップは順序通りに実行することを推奨
- ステップ間に依存関係があるため、飛ばさないように注意
- 途中で問題が発生した場合は、前のステップに戻って修正
- 定期的にgit commitで進捗を保存することを推奨
- テストは実際のゲームプレイで行い、視覚的に確認すること
