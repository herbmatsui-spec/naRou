# 🎮 Design A: スキルパラメータテーブル仕様（Ver 1.0）

本ドキュメントは、「スキル喰いの異世界倒産」に登場するスキルのマスタデータ構造および、実装予定のスキル群の一部（コモン〜コンセプト級）を展開したものです。

## 1. スキルデータ構造 (YAML/JSONスキーマ想定)

各スキルは以下のプロパティを持ちます。
- `skill_id`: 一意の識別子
- `name`: スキル名
- `tier`: 階級（Common, Rare, Unique, Concept, Eater）
- `type`: 種別（Active, Passive, Craft, Meta）
- `mp_cost`: 使用コスト（Passiveの場合は0）
- `cooldown`: 再使用待機時間
- `effects`: 効果の配列（ダメージ式、バフデバフ、特殊処理など）
- `market_value`: 換金・取引時の基本価値（単位：アルド）
- `tags`: 属性やカテゴリ（[Fire], [Combat], [Labor] など。合成時の判定に使用）
- `flavor_text`: 世界観を表すテキスト
