# フォントテクスチャアトラス

このフォルダーには、フォントテクスチャアトラスとそのメタデータが保存されます。

## ファイル
- `font_atlas.png`: フォントグリフをパッキングしたテクスチャアトラス画像
- `font_atlas.json`: アトラスのメタデータ（グリフ→UVマッピング）

## 生成方法
1. `demos/font_atlas_generator.html` をブラウザで開く
2. 必要に応じて設定を調整（デフォルト: 512x512アトラス、24x24グリフ、2ピクセルパディング）
3. 「アトラスを生成」ボタンをクリック
4. 生成されたアトラス画像を右クリックして「名前を付けて画像を保存」し、`font_atlas.png`として保存
5. JSONメタデータをコピーしてテキストファイルに保存し、`font_atlas.json`として保存
6. 両ファイルをこのフォルダーに保存

## アトラス仕様
- サイズ: 512x512 ピクセル（デフォルト、変更可能）
- 1グリフサイズ: 24x24 ピクセル（デフォルト、変更可能）
- パディング: 2 ピクセル（デフォルト、変更可能）
- 含まれるグリフ:
  - タイル文字: `@ p # . > ⛩️`
  - アイテム文字: `% ? $ * !`
  - 数字: `0-9`
  - 大文字アルファベット: `A-Z`
  - 小文字アルファベット: `a-z`

## 注意
- アトラスを更新する場合は、必ずメタデータファイルも同時に更新してください
- アトラスサイズやグリフサイズを変更した場合は、メタデータもそれに合わせて更新する必要があります
- WebGLレンダラーでは、このアトラスを使用してテキストグリフをスプライトとして描画します
