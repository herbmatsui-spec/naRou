# naRou アートスタイルガイド

## 目標スタイル
- 16-bit era JRPG 風ピクセルアート（クロノトリガー / FF6 / ロマサガ2 風）
- 16色基本パレット + アクセント色
- 左上45度光源、ドット単位の手描き感

# 基本色
- #000000: Black
- #FFFFFF: White
- #FF0000: Red
- #00FF00: Green
- #0000FF: Blue
- #FFFF00: Yellow
- #FF00FF: Magenta
- #00FFFF: Cyan
- #800000: Maroon
- #008000: Green
- #000080: Navy
- #808000: Olive
- #800080: Purple
- #008080: Teal
- #C0C0C0: Silver
- #808080: Gray

## 禁止事項
- アンチエイリアス（手動で入れる場合のみ）
- グラデーション塗り
- 3Dレンダリング風陰影
- テクスチャやフィルターエフェクト
- 写真リアリズム
- ウォーターマークやテキスト
- 署名やロゴ

## 画像仕様
- ファイル形式: PNG (透過背景必須)
- 圧縮: 無圧損または可逆圧縮
- カラープロファイル: sRGB
- ピクセルアートとしての品質: クリアなエッジ、ドット単位の意図的な配置

## アニメーション仕様
- フレームレート: 10 FPS 基準
- ループ: エフェクトはループ可能であること
- アンカーポイント: キャラクターは足元、アイテムは中心など、一貫性を持たせる

## UI 仕様
- 9-slice スケーリングに対応した設計
- コーナーは鋭角（丸みを帯びない）
- 状態別デザイン（通常/ホバー/押下/無効/フォーカス）
- アイコンサイズ: 16x16, 24x24, 32x32 など標準サイズ

## エフェクト仕様
- 加算ブレンド準備済み（黒背景が発光色を正しく表現）
- ループ可能なアニメーションフレーム数
- パーティクルシステムとの連携を考慮した設計
