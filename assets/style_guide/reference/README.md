# リファレンス画像コレクション

このディレクトリには、スタイルガイドに準拠した参考画像を収集してください。

## 収集ガイドライン
- パブリックドメイン、CC0ライセンス、または自作の画像のみを使用
- 商用利用可能な画像のみ
- 16-bit era JRPG スタイルの画像を優先
- 各カテゴリごとにサブディレクトリを作成して整理

## 推奨ソース
- OpenGameArt.org (CC0 ライセンスフィルタ適用)
- itch.io (フリーアセットセクション)
- ゲームアーカイブ（パブリックドメイン作品のみ）
- 自作ピクセルアート

## 推奨画像種類
- 地形タイル (草原、森林、砂漠、雪原など)
- キャラクタースプライト (各職業・種別)
- UI 要素 (ボタン、パネル、アイコンなど)
- エフェクト (炎、氷、稲妻など)
- ポートレート (キャラクター顔アップ)
- 背景画像 (遠景、中景、近景)

## 変換ガイドライン
収集した画像は以下に変換してください：
1. インデックスカラー化（16色パレットに変換）
2. 必要なサイズにリサイズ（16x16, 32x32, 64x64 など）
3. 透過背景を確保
4. エッジをシャープに（アンチエイリアス除去）

変換ツール例：
- Aseprite（推奨）
- GIMP（インデックスカラーモード）
- Photoshop（インデックスカラー変換）
- ImageMagick（コマンドライン）

## 使用方法
これらのリファレンス画像は：
1. スタイルガイドの作成・検証に使用
2. Gemini プロンプトのネガティブ例として使用（「これは違う」例）
3. 新人アーティストのオンボーディング資料
4. 品質チェックの基準として使用

## 更新頻度
- スタイルガイド改訂時に見直し
- 新しいアセットタイプ追加時に補充
- 四半期に一度の品質レビュー時に更新
